## 按钮文字被截断修复（同栏目）
- 用户反馈：软件更新栏目按钮「显示不正常，字被截断」。
- 根因：QPushButton 设了 `setFixedSize` + 紧凑 `padding` + `font-size: 8pt`，当文字宽度(含 padding)逼近固定宽度时 Qt 直接裁切文字边缘（不显示省略号），高 DPI / 粗体下尤明显。受影响：运行/下载(BTN_RED/BTN_GREEN_STYLE, 56×28, padding 0 10px)、检查更新(内联无 padding)、Tab(无 padding)。
- 修复（`dev/app/version_manager.py`）：
  - BTN_RED/BTN_GREEN_STYLE → `padding: 6px 14px; font-size: 9pt; min-width:56px;`；调用处 `setFixedSize(56,28)`→`(64,32)`。
  - TAB_ACTIVE/TAB_INACTIVE_STYLE → 加 `padding: 6px 8px; min-width:92px;`（按钮自身仍 100×32）。
  - 「检查更新」内联样式加 `padding: 6px 10px`，尺寸 100×30→104×32。
  - 原则：固定尺寸必须 > 文字宽 + 左右 padding，杜绝裁切。
