# 🎵 云集音乐创意台

> **把一句话，变成一首能发行的歌——全程本地，免费无限量，作品归你。**
> AI 音乐生成桌面工作台：ACE-Step 内核 + Spotify 式专业界面，装好即用，模型与产物全在本地。

## ✨ 为什么选它

| 维度 | Suno / Udio | 云集音乐创意台 |
| --- | --- | --- |
| 费用 | $10–50/月订阅 | **本地永久免费** |
| 隐私 | 云端生成 | **100% 本地，文件不出机** |
| 归属 | 平台 Licensed | **作品归你，可商用** |
| 队列 | 排队受限 | **本地批量，无限生成** |
| 定制 | 功能受限 | **内核 + 界面全可控** |

- **🎼 一句话出整曲** —— 带人声、带歌词的完整歌曲，也支持纯 instrumental
- **🎛️ 936 种风格随你挑** —— BPM / 调性 / 拍号 / 时长全可控，风格库同步自 Suno explorer
- **🧠 Thinking 模式** —— AI 自动增强提示词，低显存自动降级不挑机器
- **🎚️ 会"改歌"的工作台** —— 参考音频定风格、音频翻唱、局部重绘、种子复现
- **🎧 专业创作界面** —— Spotify 式 UI、底部播放器（波形/进度）、曲库歌单、实时进度

## 🚀 核心能力

| 类别 | 能力 |
| --- | --- |
| **整曲生成** | 带人声与歌词的完整歌曲（4 分钟+），纯 instrumental 模式 |
| **自定义模式** | BPM / 调性 / 拍号 / 时长 / 风格标签精细控制 |
| **参考与重绘** | 参考音频、音频翻唱（Audio Cover）、局部重绘、种子复现 |
| **歌词工作台** | 结构化歌词编辑器 + AI 格式助手 + 提示词模版 + 历史参数一键复用 |
| **内置工具链** | 音频编辑器（AudioMass）、人声/鼓/贝斯分轨（Demucs）、音乐视频生成、渐变封面 |
| **多语言** | 简体中文 / English / 日本語 / 한국어 四语界面 |
| **进阶训练** | LoRA / LoKR 训练支持，低显存优化 |

界面截图与多语言文档见 [`docs/pics`](docs/pics) 与 [`docs/`](docs)。

## 🎯 适用场景

- **音乐人 / 独立创作者** —— 灵感 demo 几分钟成型，成品可商用
- **短视频 / 自媒体** —— 批量产出无版权风险的原创 BGM
- **独立游戏 / 播客** —— 配乐、片头、氛围音，本地无限量
- **AI 音乐玩家** —— 想深入调参、训练自己的风格模型

## ⚡ 快速开始

```bash
# 方式一：Windows 便携桌面版（推荐）
#   双击 dist/云集智能音乐创意台-v<版本>.exe，首次自动就绪内核与模型

# 方式二：源码 / 开发模式
cd app/ace-step-ui
start-all.bat        # 一键起 API + 后端 + 前端
# 打开 http://localhost:3000 开始创作
```

| 要求 | 规格 |
| --- | --- |
| GPU | NVIDIA 4GB+ 可跑；**12GB+ 推荐**（开 Thinking / LLM） |
| 环境 | Python 3.10+（或免配环境的 Windows 便携包） |
